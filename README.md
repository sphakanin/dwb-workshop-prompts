# Dev with Bebz — Workshop Prompts

รวมพรอมป์ต์ คำสั่ง และวิธีใช้ประกอบเวิร์กช็อปของ **Dev with Bebz** เพื่อให้เปิดอ่าน คัดลอก และนำไปปรับใช้กับงานของคุณเองได้

เน้นเข้าใจวิธีทำ ไม่ผูกกับรุ่นหรือค่าย AI แต่ละเวิร์กช็อประบุสิ่งที่ต้องเตรียม ขั้นตอน และจุดที่ควรตรวจสอบไว้ในโฟลเดอร์ของตัวเอง

## เลือกเวิร์กช็อป

| ตอน | เวิร์กช็อป | เนื้อหา |
|---|---|---|
| 01 | [จาก 2 รูป สู่ Scroll-driven Cinematic Website](workshops/01-cinematic-scroll-website/README.md) | Prompt สร้างวิดีโอ, แตกเฟรมด้วย FFmpeg, Prompt สร้างเว็บ และวิธีตรวจผล |

## วิธีใช้

1. เปิดโฟลเดอร์เวิร์กช็อปที่ต้องการ แล้วอ่าน `README.md` ของตอนนั้นก่อน
2. เตรียมภาพ วิดีโอ หรือข้อมูลตามที่ระบุ
3. คัดลอกพรอมป์ต์ และเปลี่ยนค่าตัวอย่างหรือข้อความในวงเล็บให้เป็นงานของคุณ
4. ใช้เครื่องมือที่รองรับความสามารถตามโจทย์ แล้วตรวจผลจริงก่อนใช้งาน

หากต้องการดาวน์โหลดทั้งหมด เลือก **Code → Download ZIP** บนหน้า repository

พรอมป์ต์เป็นจุดเริ่มต้น ผลลัพธ์ขึ้นกับข้อมูลต้นทางและเครื่องมือที่ใช้ ตัวเลือกใช้ฟรีอาจมีโควตาหรือเงื่อนไขที่เปลี่ยนแปลงได้

## โครงสร้าง

```text
workshops/
└── 01-cinematic-scroll-website/
    ├── README.md
    ├── video-prompt.md
    ├── ffmpeg-commands.md
    └── website-prompt.md
```

เวิร์กช็อปถัดไปจะเพิ่มเป็นโฟลเดอร์ใหม่ เช่น `02-topic-name` โดยมี README อธิบายเป้าหมาย สิ่งที่ต้องเตรียม วิธีใช้ไฟล์ และวิธีตรวจผล แล้วเพิ่มลิงก์ในสารบัญด้านบน

แต่ละตอนแยกโฟลเดอร์และลิงก์ของตัวเอง เพื่อให้ลิงก์ที่ใส่ไว้ในคำอธิบายคลิปเดิมยังใช้งานต่อได้

## ขอบเขตของชุดเอกสาร

Repository นี้เก็บเอกสารประกอบการเรียน ไม่ได้รวมข้อมูลส่วนตัว API keys ไฟล์วิดีโอขนาดใหญ่ หรือผลลัพธ์สำเร็จรูป เว้นแต่ README ของแต่ละตอนจะระบุไว้

หากพบคำสั่งหรือพรอมป์ต์ที่ควรแก้ สามารถเปิด Issue พร้อมระบุชื่อเวิร์กช็อปและปัญหาที่พบได้ โดยไม่แนบข้อมูลลับ
