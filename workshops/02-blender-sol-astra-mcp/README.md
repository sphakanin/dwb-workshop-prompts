# Build Blender 3D Models with Sol + MCP and Astra

**English** · [ภาษาไทย](#ภาษาไทย) · [All workshops](../../README.md)

Companion prompts for the Dev with Bebz video:

**ปั้นโมเดล 3D ใน Blender ด้วย Astra แบบไม่เผา Codex Usage ใช้ Sol + MCP ช่วยทำงาน | ทำตามได้**

Build and review a structural model first, then use a second pass to add materials, furniture details, lighting, and decoration while preserving the approved architecture. Blender runs in the background; review the exported model in a local browser viewer.

## The two prompts

| Step | Prompt | Purpose |
|---|---|---|
| 1 | [Structural model](structural-prompt.md) | Read `plan.jpg`, document dimensions and assumptions, build the structural scene, and create a browser viewer. |
| 2 | [Visual polish](visual-polish-prompt.md) | Read the approved structural outputs and `style-reference.jpg`, capture the baseline, and decorate without changing validated architecture. |

The video uses GPT-5.6 Sol + MCP for the structural pass and Astra for visual polish. These prompts can be adapted to agents with the required capabilities. They do not install or connect MCP automatically.

## What you need

- Blender installed on the machine where the agent runs commands, with its executable available through PATH or a known full path.
- A ChatGPT/MCP setup or another compatible agent that can read images, read/write workspace files, run local commands, and use the required 3D and web tooling.
- Your own `plan.jpg`: a plan or reference drawing. Readable dimensions improve the structural input; unclear or missing measurements must remain documented assumptions.
- Your own `style-reference.jpg` for the second pass: materials, colors, furniture character, lighting, and decoration.
- A normal web browser to review the local viewer.

The workflow itself uses Blender through scripts and background execution. Opening Blender's GUI is not part of the review process.

## Step by step

1. Create a project workspace accessible to your agent and place `plan.jpg` there.
2. Give the copyable English block in [Prompt 1](structural-prompt.md) to the agent. Do not run Prompt 2 yet.
3. Read `room-spec.md` and `structural-validation.json`. Separate measured dimensions from assumptions.
4. Open the localhost URL or launcher returned by the agent. Review wall positions, dimensions, openings, and furniture blockouts. Ask for structural corrections as needed.
5. Once you are satisfied with and approve the structural model, add `style-reference.jpg` to the same workspace.
6. Give [Prompt 2](visual-polish-prompt.md) to Astra or another capable agent with access to the same files. If changing tools, transfer the complete project, including the viewer and structural outputs.
7. Compare Structural / Before and Final in the browser. Check `visual-validation.json` for evidence that the approved structural geometry was preserved.

The second prompt begins by declaring that the structure is approved. Only use that prompt after completing the review in step 4.

## Project files

These files belong in your working project, separate from this prompt repository:

```text
my-room-project/
├── plan.jpg                      # Your geometry reference
├── style-reference.jpg           # Your visual reference; used in Prompt 2
├── build_room.py                 # Generated by Prompt 1
├── room-spec.md
├── structural-validation.json
├── room-structural.blend
├── room-structural.glb
├── web-viewer/
├── OPEN-VIEWER.cmd               # Optional launcher, or an OS equivalent
├── room-final.blend              # Generated by Prompt 2
├── room-final.glb
├── room-final.png
└── visual-validation.json
```

Prompt 2 also requests a saved structural baseline. Its filename is left to the implementation. A `.blend` file is a source artifact; the browser viewer is the primary review interface. Use the local URL/port returned by the agent rather than assuming a fixed port.

All geometry-source references in Prompt 1 use **`plan.jpg`**. The supplied draft mixed `plan.jpg` and `plan.png`; this kit standardizes that filename. If your input has a different name or format, change the prompt consistently to match the real file.

## Codex Usage and scope

The demonstrated workflow does its work through ChatGPT on the web. If you perform the final stage in Codex instead, that stage uses Codex Usage. The point is to move suitable preparation and structural work out of that stage, not to promise unlimited or free model access. Model availability and usage depend on your tools and plan.

This kit contains the two prompts and instructions. It does not include reference images, generated models, a prebuilt viewer, MCP Studio, or an MCP installation guide. Bring your own inputs and use your existing MCP setup. If browser testing is unavailable, distinguish an untested viewer from one that was successfully checked.

## ภาษาไทย

# ปั้นโมเดล 3D ใน Blender ด้วย Sol + MCP และ Astra

ชุดพรอมป์ต์ประกอบวิดีโอ **ปั้นโมเดล 3D ใน Blender ด้วย Astra แบบไม่เผา Codex Usage ใช้ Sol + MCP ช่วยทำงาน | ทำตามได้**

แนวคิดคือให้ **Sol + MCP ขึ้นโครงก่อน** ตรวจและแก้ให้พอใจ แล้วค่อยให้ **Astra ตกแต่ง** โดยรักษาโครงสร้างที่ยืนยันแล้ว ใช้ Blender เป็นเครื่องมือทำงานเบื้องหลัง และตรวจผลงานผ่านเว็บบนเครื่องของเรา

## เริ่มตรงนี้

| ขั้นตอน | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| 1 | [Prompt ขึ้นโครง](structural-prompt.md) | อ่านแปลน ระบุขนาดและสมมุติฐาน สร้างโมเดลโครงสร้าง และเว็บสำหรับตรวจงาน |
| 2 | [Prompt ตกแต่ง](visual-polish-prompt.md) | รับโครงที่ยืนยันแล้ว เพิ่มวัสดุ สี แสง เฟอร์นิเจอร์ และรายละเอียด โดยไม่เปลี่ยนสถาปัตยกรรมเดิม |

คลิปใช้ GPT-5.6 Sol ในขั้นตอนขึ้นโครง และ Astra ในขั้นตอนตกแต่ง สามารถปรับใช้กับ Agent ที่มีความสามารถตามโจทย์ได้ พรอมป์ต์ชุดนี้ไม่ได้ติดตั้งหรือเชื่อม MCP ให้โดยอัตโนมัติ

## สิ่งที่ต้องเตรียม

- ติดตั้ง Blender บนเครื่องที่ Agent ใช้รันคำสั่ง และให้ Agent เรียก executable ได้ผ่าน PATH หรือระบุตำแหน่งไฟล์ให้ถูกต้อง
- เชื่อม ChatGPT กับ MCP ไว้แล้ว หรือใช้ Agent ที่อ่านภาพ อ่าน/เขียนไฟล์ และรันคำสั่งกับเครื่องมือที่จำเป็นใน Workspace ได้
- `plan.jpg` — แปลนหรือภาพต้นแบบสำหรับขึ้นโครง ถ้ามีขนาดกว้าง ยาว สูงที่อ่านได้จะช่วยให้ระบุโครงสร้างได้ชัดขึ้น ส่วนที่ไม่ทราบต้องบันทึกเป็นสมมุติฐาน
- `style-reference.jpg` — ภาพสำหรับบอกวัสดุ สี แสง และสไตล์ ใช้ในขั้นตอนที่สอง
- เว็บเบราว์เซอร์สำหรับเปิดตรวจโมเดลบน localhost

ไม่ต้องเปิด Blender GUI เพื่อตรวจงาน ให้ Agent ใช้ Blender ผ่านสคริปต์และคำสั่งเบื้องหลัง

## วิธีทำตาม

1. สร้าง Workspace ที่ Agent เข้าถึงได้ แล้ววาง `plan.jpg` ไว้ในนั้น
2. เปิด [Prompt 1](structural-prompt.md) และคัดลอกเฉพาะข้อความภาษาอังกฤษในกรอบไปใช้กับ Sol + MCP
3. อ่าน `room-spec.md` และ `structural-validation.json` ดูว่าขนาดใดอ่านจากแปลนจริง และส่วนใดเป็นสมมุติฐาน
4. เปิด URL บน localhost หรือ Launcher ที่ Agent สร้างให้ ตรวจขนาดห้อง ผนัง ประตู หน้าต่าง และตำแหน่งวัตถุ สั่งแก้โครงจนพอใจ
5. เมื่อคุณตรวจและยืนยันโครงแล้ว จึงเพิ่ม `style-reference.jpg` ลงใน Workspace เดิม
6. เปิด [Prompt 2](visual-polish-prompt.md) แล้วส่งให้ Astra ที่เข้าถึงไฟล์ชุดเดิมได้ หากเปลี่ยนเครื่องมือ ให้ย้ายโปรเจกต์พร้อมเว็บ Viewer และไฟล์โครงสร้างไปด้วย
7. สลับดู Structural / Before กับ Final ในเบราว์เซอร์ และตรวจ `visual-validation.json` ว่าโครงสร้างที่ล็อกไว้ยังเหมือนเดิม

**อย่าส่งสองพรอมป์ต์รวดเดียว:** Prompt 2 เริ่มด้วยข้อความว่าโครงได้รับการยืนยันแล้ว จึงควรใช้หลังจากคุณตรวจโครงจาก Prompt 1 และพอใจกับผลจริง

## แปลนกับภาพสไตล์มีหน้าที่ต่างกัน

- `plan.jpg` กำหนดรูปทรง ขนาด และตำแหน่งโครงสร้าง
- `style-reference.jpg` ใช้บอกวัสดุ สี บรรยากาศ และลักษณะการตกแต่ง
- หากภาพสไตล์ขัดกับแปลน ต้องรักษาโครงจากแปลนและปรับสไตล์ให้เข้ากับโครงนั้น
- `.blend` เป็นไฟล์ต้นทางสำหรับแก้และสร้างงาน ส่วนการตรวจตามปกติให้ใช้โมเดล `.glb` ในเว็บ Viewer

ชุดนี้แก้ชื่อภาพใน Prompt 1 ให้เป็น **`plan.jpg` ทุกจุด** เพราะร่างเดิมมีทั้ง `plan.jpg` และ `plan.png` หากใช้ชื่ออื่น ให้แก้ทุกจุดในพรอมป์ต์ให้ตรงกับไฟล์จริง ใช้ URL และพอร์ตที่ Agent แจ้งจากการรันจริง

## เรื่อง Codex Usage และขอบเขตชุดนี้

เดโมในคลิปทำงานผ่าน ChatGPT บนเว็บ หากเลือกไปทำขั้นตอนสุดท้ายใน Codex ขั้นตอนนั้นจะใช้ Codex Usage แนวทางนี้ช่วยย้ายงานเตรียมและขึ้นโครงที่เหมาะสมออกไปก่อน ไม่ได้หมายความว่าทุกโมเดลใช้ฟรีหรือไม่มีลิมิต สิทธิ์และโควตาขึ้นกับเครื่องมือและแพลนที่ใช้

โฟลเดอร์นี้มีพรอมป์ต์สองชุดและวิธีใช้ ไม่ได้แนบภาพอ้างอิง โมเดลสำเร็จรูป เว็บ Viewer สำเร็จรูป ตัว MCP Studio หรือคู่มือติดตั้ง MCP ให้ใช้ภาพของคุณเองและ MCP ที่เชื่อมไว้แล้ว หากเครื่องมือทดสอบเบราว์เซอร์ไม่ได้ ต้องแยกให้ออกระหว่างงานที่ยังไม่ทดสอบกับงานที่ตรวจผ่านแล้ว
